1. High-Level Architecture Overview

The analyzed script implements a complete autoregressive language model inspired by OpenAI's GPT architecture and nanoGPT.

Core Execution Workflow:

  • Data Subsystem: Subword tokenization via BERT tokenizer and custom PyTorch data loading batching.
  • Attention Engine: Causal single-head & multi-head self-attention mechanism.
  • Transformer Blocks: Stacked multi-head attention and feed-forward networks with residual skip connections.
  • Inference & Generation: Autoregressive loop with temperature scaling for context sampling.

2. Tokenization & Data Loader

The code uses standard BERT subwords for tokenization and extracts training/validation tensors on demand.

Data Split & Target Alignment:

  • Inputs (x): Sequence block of context length T (e.g. 256 tokens).
  • Targets (y): Identical sequence shifted 1 position right ($y_t = x_{t+1}$).
class TokenizeDataLoader: def get_batch(self, split='train', batch_size=4, block_size=256): data_set = self.train_data if split == 'train' else self.val_data # Random starting index selection max_idx = max(1, len(data_set) - block_size) ix = torch.randint(0, max_idx, (batch_size,)) # Shift target by 1 token to right x = torch.stack([data_set[i:i + block_size] for i in ix]) y = torch.stack([data_set[i + 1:i + block_size + 1] for i in ix]) return x.to(self.device), y.to(self.device)

3. Single Causal Attention Head

Calculates scaled dot-product attention with causal mask to prevent attending to future tokens.

Scaling Bug Discovered
Code Analysis & Discovered Scaling Bug
# Original implementation in ee.py def forward(self, x): B, T, C = x.shape k = self.key(x) q = self.query(x) # BUG: Scaled using full embedding dimension C instead of head_size (d_k) wei = q @ k.transpose(-2, -1) * (C**-0.5) # Causal Masking wei = wei.masked_fill(self.tril[:T, :T] == 0, float('-inf')) wei = F.softmax(wei, dim=-1) out = wei @ self.value(x) return out

Bug Explanation & Fix

In standard Multi-Head Attention, dot products are scaled by $\sqrt{d_k}$ (where $d_k = \frac{n_{\text{embd}}}{n_{\text{head}}}$), not $\sqrt{n_{\text{embd}}}$.

Incorrect Scale = C**-0.5

Correct Scale = (C // num_heads)**-0.5

4. Multi-Head Attention Mechanism

Runs multiple single attention heads in parallel, enabling the model to jointly attend to information from different representation subspaces.

class MultiHeadAttention(nn.Module): def __init__(self, num_heads, head_size, n_embd, block_size, dropout): super().__init__() # Parallel Attention Heads self.heads = nn.ModuleList([ Head(head_size, n_embd, block_size, dropout) for _ in range(num_heads) ]) # Output Linear Projection self.proj = nn.Linear(n_embd, n_embd) self.dropout = nn.Dropout(dropout) def forward(self, x): # Concatenate head outputs along channel dimension out = torch.cat([h(x) for h in self.heads], dim=-1) out = self.dropout(self.proj(out)) return out

5. Transformer Block Architecture

Integrates attention mechanisms with Feed-Forward Neural Networks (FFN) and Layer Normalization.

LayerNorm Placement Fix
class Block(nn.Module): def __init__(self, n_embd, n_head, block_size, dropout): super().__init__() head_size = n_embd // n_head self.sa = MultiHeadAttention(n_head, head_size, n_embd, block_size, dropout) self.ln1 = nn.LayerNorm(n_embd) self.ffwd = FeedForward(n_embd, dropout) self.ln2 = nn.LayerNorm(n_embd) def forward(self, x): # Recommended Modern Pre-LN Standard: x = x + self.sa(self.ln1(x)) x = x + self.ffwd(self.ln2(x)) return x

Pre-LN vs Post-LN Architecture

Modern GPT models (including GPT-2/3/4) place LayerNorm before the attention block and feedforward block (Pre-LN) for improved gradient stability during training.

Inference Best Practices

  • Temperature Scaling: Lower temperatures ($< 0.7$) yield deterministic outputs; higher values yield creative text.
  • State Loading: Ensure weights loaded via torch.load() are properly populated into the target model instance via load_state_dict().
