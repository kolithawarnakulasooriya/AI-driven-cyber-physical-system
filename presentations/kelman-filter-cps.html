Bayes' Theorem

  • Conditional probability: Quantifies the likelihood of an event occurring relative to the occurrence of another linked event.
  • Likelihood of Event A occurring where another event B has occurred:
P(A given B) equals P(A and B) divided by P(B), where P(B) is greater than 0.
  • Bayes' Theorem framework: Provides a systematic methodology to calculate posterior probabilities using prior tracking knowledge.
P(A given B) times P(B) equals P(B given A) times P(A).
Therefore, P(A given B) equals P(B given A) times P(A) divided by P(B).

Sensor Probability Example

  • Positioning sensor precision maintains an 80% baseline accuracy value. Trajectory turning variations display a static 50% baseline distribution.
  • Evaluations target performance across distinct sensor observation profiles:
    • P(left) = 0.5, P(right) = 0.5, Probability of sensor reading P(z)
    • P(z = left | x = left) = 0.8, P(z = left | x = right) = 0.2
    • P(z = left) = 0.8 * 0.5 + 0.2 * 0.5 = 0.5
  • Derived system probability outputs:
    • Sensor = Left, Actual = Left: P(x = left | z = left) = 0.8 * 0.5 / 0.5 = 0.80 (80%)
    • Sensor = Left, Actual = Right: P(x = right | z = left) = 0.2 * 0.5 / 0.5 = 0.20 (20%)

What is State Estimation?

  • Processes mathematical frameworks to extract deterministic parameters out of noisy sensor profiles.
  • Relies upon a structured history of dynamic parameters:
    • System State vector at time parameter t: x_t
    • Sensor Observation profiles at time parameter t: z_t
    • Control Input vectors at time parameter t: u_t
  • Sequential Event Order:
    • 1. A system control input u_t is initiated.
    • 2. Structural system state variables transition to x_t.
    • 3. A measurement observation validation z_t is acquired.

Markov Assumption

  • Dynamic profiles assume event outcomes remain dependent solely on the immediately preceding systemic step:
The current output depends only on the most recent previous state, not on the full history.
  • State transition evaluations ignore chronological historical variations, relying directly on immediate states and incoming inputs:
The current state depends on the previous state and the latest control input.
  • Observation accuracy profiles depend directly on current target parameters:
The current observation depends on the current state rather than on the full sequence of past states.
  • Operational Constraints: Environment remains static; system error patterns are uncorrelated; transition structures are modeled perfectly.

Gaussian Distributions

  • Forms a symmetrical, continuous bell curve centered precisely around the calculated tracking mean.
  • Mean (mu): Identifies the central amplitude point or maximum likelihood peak within the curve.
  • Standard Deviation (sigma): Governs distribution width. Narrow contours signify high certainty; wide profiles show lower precision.
The Gaussian distribution is a bell-shaped probability model described by a mean and a variance. Its density is centered around mu and controlled by sigma.

Recursive Belief Equation

  • Maintains real-time recursive system updates across operations using historical belief (x), input commands (u), and active observations (z).
Belief at time t is the normalized product of the current measurement likelihood and the belief propagated from the previous time step.
  • Bayes Filter Phase Division:
    • Prediction Phase: Formulates system expectation prior to integration of sensor telemetry.
      Prediction step: propagate the previous belief through the motion model before adding the new observation.
    • Correction Phase: Filters prediction parameters via incoming real-time sensor evaluations.
      Correction step: update the predicted belief using the latest sensor measurement.

  • Dynamic Target Scenario: Target shifts tracking location with velocity parameters V = 15 m/s across time span T = 2s.
  • System integration model: x_new = x_old + v*t
  • Velocity deviation holds 0.7 uncertainty: N(15, 0.7^2)
  • Combining two independent Gaussian tracking contours:
The predicted mean is the previous mean plus the motion term, giving 25. The predicted variance is the sum of the previous variance and the process variance, giving 1.49.
  • Calculated forward prediction distribution state:
The predicted state is approximately 25 with variance 1.49.

1D Filtering: Correction

  • Executes correction loops by cross-checking predicted configurations against active sensors.
    • The correction step combines the predicted estimate with the latest sensor reading.
  • A secondary validation profile identifies an object reading at 24m containing a variance factor of 0.4: N(24, 0.4)
  • Fusing the operational profiles: N(24, 0.4) * N(25, 1.49)
The fused estimate is approximately 24.97 with variance 0.144, which is more confident than either source alone.

Prediction Phase

Multi-Dimensional Filtering

Update Phase

  • Measurement Residual (y_t): Mathematical deviation mapping actual sensor outputs directly against internal predictive physics matrices:
The measurement residual is the difference between the observed value and the predicted measurement.
  • Kalman Gain Matrix (K_t): Scale factor evaluating prediction model variance weights against inbound observation error matrix R:
The Kalman gain balances the uncertainty of the prediction against the uncertainty of the measurement.
  • State and covariance matrices finalize via integrated innovation feedback equations:
The updated state is the predicted state plus the gain times the residual, and the covariance is reduced accordingly.
