1. Goal

Learn language structure from characters

The notebook trains a small neural model to predict the next character in a text sequence. Instead of using a large pretrained model, it builds the network from scratch and learns patterns directly from the provided text.

What the model learns

  • Word-like patterns and punctuation
  • Repeated phrases and structure
  • Simple grammar and style

Why it is useful

  • Good for teaching transformer concepts
  • Shows how embeddings and attention work
  • Provides a foundation for larger models

2. Dataset and tokenization

Characters become integers

The Dataset class maps each unique character to an index and builds a vocabulary. This turns raw text into tensor values that the model can process.

class Dataset(): def __init__(self, data): self.chars = sorted(list(set(self.data))) self.stoi = {ch: i for i, ch in enumerate(self.chars)} self.itos = {i: ch for i, ch in enumerate(self.chars)}

3. Attention mechanism

Self-attention lets the model look at context

Each token creates queries, keys, and values. Attention scores determine how much each earlier token should influence the current prediction.

Q = XWQ, K = XWK, V = XWV
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V

A causal mask ensures the model only attends to prior positions, which is essential for autoregressive generation.

4. Architecture

Multiple heads and transformer blocks

Multi-head attention

Several attention heads run in parallel, each learning different relationships in the sequence.

Feed-forward layer

After attention, a small dense network transforms the token representation further.

Block structure

Each Transformer block combines self-attention, layer normalization, a feed-forward network, and residual connections.

5. Training loop

Predict the next token and learn from error

Training batches are built as windows of characters, where the input sequence predicts the next token in the sequence. The output logits are compared with the target tokens using cross-entropy loss.

xb, yb = dataset.get_batch('train', batch_size=32, block_size=64) logits, loss = model(xb, yb) optimizer.zero_grad(set_to_none=True) loss.backward() optimizer.step()

6. Generation and saving

From trained weights to text

Save the model

The trained weights are saved to disk so the model can be reused later.

from pathlib import Path torch.save(model.state_dict(), f'{Path.cwd()}/../models/simple_gpt.pth')

Generate text

Starting from a short context, the model repeatedly samples the next token and appends it to the sequence.

context = torch.zeros((1, 1), dtype=torch.long, device=device) generated_tokens = model.generate(context, max_new_tokens=60)
