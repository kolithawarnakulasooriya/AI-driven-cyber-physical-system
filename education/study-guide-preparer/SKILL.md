# Study Guide Preparer

This skill generates structured study guides that break down complex topics into digestible sections, provide definitions, examples, and hands‑on exercises. It is intended for creating onboarding documentation, certification prep, or self‑directed learning paths.

## When to Use
- Designing a learning module for a new feature or concept.  
- Preparing onboarding material for new team members.  
- Creating study materials for certification or exam preparation.  
- Documenting step‑by‑step lab instructions for hands‑on practice.

## Prerequisites
- Access to the project’s documentation, API references, or codebase.  
- Familiarity with the target audience’s skill level.  
- Desired learning objectives or key concepts to cover.

## How to Run
Use the `terminal` tool to invoke the skill script or call the skill directly:

```bash
skill_load study-guide-preparer
```

Then provide the topic and any specific requirements via the skill’s input parameters.

## Quick Reference
- `skill_load study-guide-preparer` – load the study‑guide‑preparer skill.  
- Provide a topic string and optional audience level (e.g., “Beginner”, “Intermediate”).  
- Receive a markdown study guide ready for review.

## Procedure
1. **Gather input** – supply a concise topic description and audience level.  
2. **Generate outline** – the skill creates a section hierarchy (Foundations, Core Concepts, Advanced Topics, Labs).  
3. **Write content** – populate each section with definitions, examples, and command snippets where applicable.  
4. **Add verification steps** – include commands to run tests or experiments that confirm understanding.  
5. **Review and polish** – verify that the generated guide aligns with the provided requirements and style conventions.

## Pitfalls
- Over‑generating verbose text that exceeds typical README length; keep sections concise.  
- Missing critical prerequisites or assuming knowledge not yet covered; double‑check audience level.  
- Generating outdated command examples; always verify that code snippets reflect the current API.  
- Not adapting tone for the target audience; ensure language matches the intended readers.

## Verification
- Execute the generated guide’s “Verification” commands to confirm they run without error.  
- Compare the output against expected results to ensure accuracy.  
- Optionally, render the markdown to verify formatting.

## Automated Presentation Guide Generation
The following procedural steps can be used to automatically generate a `study-guide.md` for each feature branch:

1. **Create the presentation directory** (if it does not exist):
   ```bash
   mkdir -p presentation
   ```

2. **List feature branches** (excluding `main` and `presentations`):
   ```bash
   git branch --format=%(refname:short) |
   grep -v '^main$' |
   grep -v '^presentations$' |
   while read branch; do
       # Create a subdirectory for the branch
       mkdir -p "presentation/$branch"
       # Copy the study‑guide‑preparer template into the subdirectory as study‑guide.md
       cp .agents/agents/study-guide-preparer.md "presentation/$branch/study-guide.md"
   done
   ```

3. **Result**: Each branch now has a `presentation/<branch>/study-guide.md` file containing the study‑guide template, ready for further customization.

*Note:* Adjust the branch‑filtering command if your repository uses a different naming convention.
