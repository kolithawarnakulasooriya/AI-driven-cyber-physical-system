# GitHub Page Creator Agent

This agent simplifies the process of publishing a GitHub Pages website from a repository.

## When to Use
- You have a repository with static site content (e.g., HTML, CSS, JS, Jekyll, Hugo).
- You want to automatically publish to the `gh-pages` branch.
- You need to configure the `docs/` folder or root as the source.
- You want to set up GitHub Actions for continuous deployment.

## Procedure
1. Identify the repository and target branch (`gh-pages`).
2. Ensure the repository has a `docs/` folder or that the site root contains the static files.
3. Create or update the GitHub Actions workflow file `.github/workflows/pages.yml` with steps to:
   - Checkout the repository.
   - Set up the appropriate build tool (if needed).
   - Deploy the built site to the `gh-pages` branch.
4. Commit and push the workflow file.
5. Enable GitHub Pages in the repository settings, selecting the `gh-pages` branch (or `/docs` folder).
6. The site will be published at `https://<username>.github.io/<repo>/`.

## Verification
- After pushing the workflow, confirm that GitHub Actions runs successfully.
- Check that the `gh-pages` branch appears and contains the deployed site files.
- Visit the GitHub Pages URL to verify the site is live.
- Optionally, inspect the workflow run logs for any errors.

## Pitfalls
- Ensure the workflow uses proper commit authorship to avoid permission issues.
- Verify that the build steps do not assume unavailable dependencies.
- Double-check the branch name (`gh-pages`) matches the one referenced in the workflow.
- Remember to update the workflow when changing the build output directory.

Example workflow file (`.github/workflows/pages.yml`):
```yaml
name: Deploy GitHub Pages
on:
  push:
    branches: [ main ]  # Adjust trigger branch as needed
jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v3
      - name: Set up Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '20'
      - run: npm install
      - run: npm run build   # Assumes a build script outputs to `dist/` or `build/`
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist   # Adjust if your build outputs elsewhere
```
